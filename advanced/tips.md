# ⚡ 效率提升技巧

> 20 个 Claude Code 日常使用技巧，帮你从「能用」到「好用」。

---

## 🖥️ 终端操作技巧

### 1. 用 `/` 命令代替自然语言

```
# ❌ 慢
"帮我创建一个新的 React 组件，名字叫 Button"

# ✅ 快
/init    # 初始化项目
# 然后告诉 Claude 要做什么
```

Claude Code 的 `/` 命令是快捷入口，比自然语言描述更快。

### 2. 拖拽文件夹到终端

不用手动输入路径，直接把文件夹从文件管理器拖入终端即可填充路径。

### 3. `Ctrl+R` 搜索历史命令

在终端中按 `Ctrl+R`，输入关键词可以快速找到之前的命令，不必重新输入。

### 4. 用 `!!` 重复上一条命令

```bash
# 假设你刚执行了一个需要 sudo 却忘加的命令
sudo !!
```

### 5. Tab 自动补全

输入文件名、路径或命令时按 Tab 自动补全，大幅减少输入量。

## 🎯 Claude Code 交互技巧

### 6. 给 Claude 足够的上下文

```
# ❌ 模糊
"修一下这个 bug"

# ✅ 清晰
"用户点击登录按钮后页面卡在 loading 状态，检查 auth.ts 中的 login 函数，可能是 API 返回格式变更导致的"
```

### 7. 善用 `/compact` 保持会话清爽

当对话很长时，主动执行 `/compact` 压缩上下文：
- 保留关键决策和约定
- 丢掉冗余的中间讨论
- Claude 响应速度更快

### 8. 用 `/add-dir` 快速切换项目

```bash
/add-dir /path/to/another/project
```

不用退出重启，直接添加另一个项目目录。

### 9. 一次描述多个需求

```
"做三件事：
1. 在 utils.ts 加一个日期格式化函数
2. 在 Button 组件中使用这个函数
3. 更新测试"
```

Claude Code 会按顺序处理，比一个一个说高效得多。

### 10. 用@符号引用文件

```
看一下 @src/utils/auth.ts 中的 login 函数，帮我加错误重试逻辑
```

直接引用文件，Claude 会自动读取。

## 🧩 工作流技巧

### 13. 创建常用任务的别名

在 `.claude/settings.json` 中，可以用 Hooks 和 Workflow 组合来自动化常见操作。

### 14. 将项目规范文档化

在项目根目录创建 `CLAUDE.md` 文件，写入项目约定：

```markdown
# CLAUDE.md

## 项目规范
- 使用 TypeScript strict 模式
- 组件必须包含 PropTypes
- API 调用统一用 src/api/ 下的封装
- 样式使用 CSS Modules
```

Claude Code 会优先参考这个文件，输出更符合你的项目风格。

### 15. 设定明确的约束

```
"重构这个模块，但是：
- 不能改 API 接口签名
- 不能引入新的依赖
- 保持向后兼容"
```

约束越清晰，Claude 的输出越可控。

## 🔌 集成技巧

### 16. Claude Code + VSCode 联动

在 VSCode 中打开终端使用 Claude Code，可以：
- 左边看代码，右边跟 Claude 对话
- Claude 生成的文件直接在 VSCode 中打开
- 用 VSCode 的 Git 面板管理变更

### 17. 善用 Git 管理 Claude 的修改

```bash
# Claude 每次修改后
git diff          # 查看变更
git add -p        # 选择性暂存
git commit -m "..."
```

不要直接接受所有改动，先 review。

### 18. 用 Claude Code 生成 Git Commit Message

```
"帮我给这次的改动写一个规范的 commit message"
```

## 💡 思维模式

### 19. 把 Claude Code 当「高级同事」而非「搜索引擎」

- ❌ 「什么是闭包？」（搜文档就够了）
- ✅ 「这段闭包代码有什么问题？怎么优化？」

### 20. 先小范围验证，再大规模铺开

```
# 先让 Claude 改一个小模块
"重构 utils/date.ts 中的 3 个函数"

# 验证没问题后，再告诉它
"按照同样的风格重构 utils/ 下所有文件"
```
